# 💰 FinanceFlow 2.0

## Personal Finance Tracker

### 1. Project Overview

FinanceFlow 2.0 is a responsive personal finance management application that helps users track income and expenses, manage monthly budgets, set savings goals, monitor recurring transactions, and understand their spending habits through an interactive dashboard.

### 2. Objective

The main objective of FinanceFlow 2.0 is to provide a simple and organized digital solution for managing personal finances and reducing the need for manual calculations and record keeping.

### 3. Key Features

* 💰 Income tracking
* 🧾 Expense tracking
* 💵 Automatic balance calculation
* 🎯 Monthly budget management
* 🏆 Savings goal tracking
* 🔁 Recurring transaction templates
* 📋 Transaction history
* 🔎 Search and filtering
* ✏️ Edit transactions
* 🗑️ Delete transactions
* 📈 Income vs Expense analysis
* 📊 Spending by category
* 🧠 Financial insights

### 4. Dashboard

The dashboard provides a financial overview containing:

* Total Income
* Total Expense
* Available Balance
* Monthly Budget
* Savings Rate

Income: ₹10,000
Expense: ₹200
Balance: ₹9,800

### 12. Financial Calculations

Balance is calculated as:

Balance = Total Income − Total Expense

Savings Rate is calculated as:

Savings Rate = (Income − Expense) / Income × 100

Budget Usage is calculated as:

Budget Usage = Expense / Budget × 100

Savings Goal Progress is calculated as:

Goal Progress = Saved Amount / Target Amount × 100

* Current data is stored in the browser.
* No direct bank-account integration.
* Advanced financial forecasting is not included.
* Data can be lost if browser storage is cleared.
