# 💰 FinanceFlow 2.0

### Personal Finance Tracker

FinanceFlow 2.0 is a responsive personal finance management application designed to help users track income and expenses, manage monthly budgets, set savings goals, monitor recurring transactions, and understand their spending habits through an interactive dashboard.

---

## 🚀 Features

* 💰 Income tracking
* 🧾 Expense tracking
* 📊 Financial overview dashboard
* 💵 Automatic balance calculation
* 🎯 Monthly budget management
* 🏆 Savings goal tracking
* 🔁 Recurring transaction templates
* 📋 Transaction history
* 🔎 Transaction filtering
* ✏️ Edit transactions
* 🗑️ Delete transactions
* 📈 Income vs Expense visualization
* 🥧 Spending by category visualization
* 🧠 Financial insights
* 💡 Financial tips
* 📤 CSV export
* 📱 Responsive user interface
* 🔒 Browser-based data storage

---

## 📊 Dashboard

FinanceFlow provides a financial overview containing:

* Total Income
* Total Expense
* Available Balance
* Monthly Budget
* Savings Rate
* Savings Goal Progress

Example:

```text
Total Income       ₹10,000
Total Expense         ₹200
Balance             ₹9,800
Monthly Budget      ₹1,000
Savings Rate           98%
```

## 🎯 Budget Management

Users can set a monthly spending limit and monitor how much of their budget has been used.

For example:

```text
Monthly Budget: ₹1,000
Expense:        ₹200
Budget Used:       20%
Remaining:       ₹800
```

---

## 🏆 Savings Goals

Users can create a savings target and monitor progress toward that goal.

Example:

```text

Progress:       2%
Remaining:    ₹490
```

## ⚙️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/FinanceFlow-2.0.git
```

### 2. Open the project folder

```bash
cd FinanceFlow-2.0
```

### 3. Run the application

Open `index.html` in a web browser.

For the best development experience, you can use the **Live Server** extension in Visual Studio Code.

---

## 💾 Data Storage

FinanceFlow stores user financial data in the browser.

This allows the application to work without requiring a backend server or external database for the current version.

---

## 🔐 Privacy

FinanceFlow is designed with browser-based data storage, so the application's financial records remain in the user's browser rather than being sent to a remote server in the current implementation.
